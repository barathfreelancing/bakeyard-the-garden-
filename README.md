# Bakeyard — The Garden Cafe

A responsive, static website for Bakeyard in Gunjur, Whitefield, Bengaluru.

## Open locally

Open `index.html` in a browser. No build step or package installation is required.

## Files

- `index.html` — page content, SEO metadata, and local business structured data.
- `styles.css` — responsive visual system and motion behavior.
- `script.js` — mobile menu, scroll header, reveal effects, and gallery lightbox.

The page uses cafe photos from the public District listing and externally hosted Google Fonts and map embed. The District rating shown is the live listing snapshot used while building (42 ratings; category scores 4.7 Food, 4.8 Ambience, 4.7 Service); ratings can change over time.
